# 쇠타임 (soetime)

광고 없는 운동 휴식 타이머. 서버 없이 브라우저 안에서만 동작하는 모바일 PWA입니다.

---

## 주요 특징

1. **정확한 휴식 타이머**
   - 흘러간 시간을 세지 않고 **끝나는 시각**을 기억합니다. 다른 앱을 쓰다 돌아와도,
     앱이 종료됐다 다시 열려도 남은 시간이 어긋나지 않습니다.
   - 프리셋 버튼으로 한 번에 시작, 진행 중 ±15초 조절, 완료 후 같은 시간으로 재시작.

2. **화면 꺼짐 방지 (Screen Wake Lock)**
   - 타이머가 도는 동안 화면이 꺼지지 않습니다.
   - 앱 전환 후 돌아오면 자동으로 다시 적용됩니다.
   - iOS 홈 화면 앱에서는 iOS 18.4 이상이 필요합니다. 지원하지 않으면 안내만 하고 계속 동작합니다.

3. **완료 알림**
   - 소리(오디오 파일 없이 즉석 생성 → 오프라인에서도 동작)와 진동.
   - 진동은 iOS에서 지원하지 않습니다.
   - 화면을 잠근 상태에서는 소리가 울리지 않습니다. 서버 없이 백그라운드 알림을 보낼 수
     없기 때문이며, 돌아오면 "N분 전에 끝남"으로 알려줍니다.

4. **완전 오프라인 / 서버 없음**
   - 모든 설정은 브라우저 `localStorage`에만 저장되고 외부로 전송되지 않습니다.
   - 지하 헬스장처럼 신호가 약한 곳에서도 동작합니다.

---

## 스마트폰 홈 화면에 설치하는 법

- **iOS (Safari)**: 하단 [공유] → [홈 화면에 추가]
- **Android (Chrome / 삼성인터넷)**: 상단 메뉴 → [앱 설치] 또는 [홈 화면에 추가]

---

## 로컬 개발 및 빌드

```bash
npm install
npm run dev
npm run build
```
